# HRMS Employee Management – QA Testing Portfolio

## About This Project

This is an independent QA portfolio project focused on testing a fictional Human Resource Management System (HRMS).

The project demonstrates my understanding of software testing, test case design, API testing, automation, and quality assurance practices.

## Application Under Test

A fictional HRMS application with features such as:

- Employee registration
- Employee profile management
- Attendance management
- Leave management
- Payroll management

## Tools and Technologies

- Manual Testing
- Postman – API Testing
- JavaScript
- Playwright – UI Automation
- Git and GitHub
- GitHub Actions – CI/CD
- Generative AI for Test Design

## My QA Approach

My approach is to understand requirements, identify risks, ask questions when requirements are unclear, design test cases, execute tests, report verified defects, and automate suitable scenarios.
